Make → Leads App Integration Guide

Instructions for connecting Make.com scenario to the TreeCheck leads application

1. Webhook Endpoint

Use this URL in your Make HTTP module:

https://wsbtxxobbvcdxiovnssi.supabase.co/functions/v1/create-lead

2. HTTP Module Configuration

Add an HTTP "Make a request" module at the end of your scenario after the estimate, job type, and address have all been finalized.

Setting Value
URL https://wsbtxxobbvcdxiovnssi.supabase.co/functions/v1/create-lead
Method POST
Body type Raw
Content type JSON (application/json)

Required Headers

Header Name Header Value
Content-Type application/json
X-Webhook-Secret [Secret provided separately - do not share in documents]

3. Request Body (JSON)

Map your scenario variables to this JSON structure:

{
  "photo_url": "{{photo_url_from_form}}",
  "city": "{{city_from_form}}",
  "customer_name": "{{name_from_form}}",
  "customer_email": "{{email_from_form}}",
  "customer_phone": "{{phone_from_form}}",
  "customer_address": "{{full_address_from_form}}",
  "estimated_cost_min": {{min_price_number}},
  "estimated_cost_max": {{max_price_number}},
  "job_type": "{{job_type_from_form_or_classifier}}",
  "urgency": "{{urgency_from_form}}"
}
Important: The price fields (estimated_cost_min and estimated_cost_max) must be numbers without quotes. Also, job_type must be mapped from the same source you use in any homeowner text and must resolve to one of these values: Tree Removal, Stump Grinding, or Pruning/Trimming.

4. Field Requirements

Field Type Notes
photo_url String Must be a publicly accessible image URL
city String City name only, e.g. "Yukon" or "Newalla" — must match contractor service areas
customer_name String Customer's full name
customer_email String Customer's email address
customer_phone String Customer's phone number
customer_address String Full address line for the lead
estimated_cost_min Number Lower bound of price range (no quotes, no $)
estimated_cost_max Number Upper bound of price range (no quotes, no $)
job_type String Required. Must be Tree Removal, Stump Grinding, or Pruning/Trimming. Lowercase variants like tree removal and pruning are normalized automatically.
urgency String Optional. Supported values: Emergency, As soon as possible, Within a month, Flexible

5. Expected Responses

Success (201)

{
  "success": true,
  "lead_id": "uuid-of-created-lead",
  "job_type": "Tree Removal",
  "urgency": "Flexible",
  "message": "Lead created successfully"
}

Error Responses

Status Meaning
401 Wrong or missing X-Webhook-Secret header
400 Missing required field, invalid job_type, or invalid data format
500 Server error — contact administrator

6. Testing

Before going live:

  1. Run the scenario with test data
  2. Check for a 201 success response
  3. Verify the lead appears in the contractor dashboard with the correct job type
  4. Confirm the homeowner text and the stored lead use the same job type wording
  5. Confirm the image displays correctly
