n8n Integration Guide

Send a Lead to the TreeCheck Contractor App

Overview

Homeowners submit the tree estimate form on the WordPress site (treecheck.ai). The form fires a webhook into n8n, where GPT generates an estimate and emails the homeowner. After that step, n8n must POST the lead into the TreeCheck contractor app so local arborists can unlock and contact the customer.

WordPress Form → n8n Webhook → GPT Estimate → Homeowner Email + POST to create-lead (this guide)

Request Body

{
  "photo_url": "https://example.com/uploads/tree-photo.jpg",
  "city": "Oklahoma City",
  "customer_name": "Jane Doe",
  "customer_email": "jane@example.com",
  "customer_phone": "+14055551234",
  "customer_address": "123 Main St, Oklahoma City, OK 73102",
  "estimated_cost_min": 850,
  "estimated_cost_max": 1400,
  "job_type": "Tree Removal",
  "urgency": "As soon as possible"
}

Field Reference

FieldTypeRequiredDescription / Rules
photo_urlstring (URL)YesPublic URL to the tree photo. Must be http:// or https://. Max 2048 chars. The app auto-downloads it into our private storage so the link can later go dead without breaking the lead.
citystringYesCity name only — e.g. "Oklahoma City", "Edmond", "Austin". Used to match contractors by service area. Max 200 chars.
customer_namestringYesFull name from the form. Max 200 chars.
customer_emailstringYesMust be a valid email. Max 320 chars.
customer_phonestringYesE.164 (e.g. +14055551234) or US format (e.g. (405) 555-1234). Max 50 chars.
customer_addressstringYesFull street address — contractors click this to open Google Maps. Max 500 chars.
estimated_cost_minnumberYesLow end of the GPT estimate, in dollars. Must be ≥ 0.
estimated_cost_maxnumberYesHigh end of the GPT estimate, in dollars. Must be ≥ estimated_cost_min and ≤ 1,000,000.
job_typestring (enum)YesMust be one of: "Tree Removal", "Stump Grinding", "Pruning/Trimming". Common aliases like "trimming" or "removal" are auto-normalized, but please send the canonical value when possible.
urgencystring (enum)NoOne of: "Emergency", "As soon as possible", "Within a month", "Flexible". Defaults to "Flexible" if omitted. Aliases like "ASAP" are auto-normalized.
💡 Testing: To test end-to-end without showing the lead to real contractors, send "city": "Testville". This city is reserved for QA and only visible to admin accounts.

Successful Response 201

{
  "success": true,
  "lead_id": "a1b2c3d4-...",
  "job_type": "Tree Removal",
  "urgency": "As soon as possible",

Error Responses

StatusMeaningAction
400Missing field, invalid email/phone, invalid URL, bad cost range, or unknown job_typeCheck the JSON body against the field reference above. The response body has an error field explaining which validation failed.
401Missing or wrong x-webhook-secretVerify the header value matches exactly.
405Wrong HTTP methodUse POST.
500Server errorRetry. If it persists, contact the TreeCheck team.

n8n Node Setup

1
After the GPT estimate step, add an HTTP Request node.
2
Method: POST
3
URL: https://wsbtxxobbvcdxiovnssi.supabase.co/functions/v1/create-lead
4
Under Headers, add:
Content-Type = application/json
x-webhook-secret = 5jhj47_C_P5_H5i
5
Body type: JSON — map every required field from the form data + GPT output. Example expressions:
"photo_url": "{{ $json.photo_url }}"
"city": "{{ $json.city }}"
"estimated_cost_min": {{ $json.gpt_low }}
"estimated_cost_max": {{ $json.gpt_high }}
(numbers must NOT be wrapped in quotes)
6
Run the workflow with a test submission. A 201 response with a lead_id means success — the lead now appears in the contractor dashboard.

Common Pitfalls

SymptomLikely Cause
401 UnauthorizedHeader name is misspelled, or value has trailing whitespace.
400 "Invalid cost range"estimated_cost_min / estimated_cost_max were sent as strings instead of numbers, or min > max.
400 "Invalid job_type"Sent something outside the three canonical values and the alias list. Map the form's dropdown to one of the three exactly.
400 "Invalid phone format"Phone has extra characters (extension, "x123", letters). Strip to digits or send E.164.
400 "Missing required field: customer_address"The WordPress form field for address didn't make it through. Check field name mapping in n8n.
Lead created but contractors don't see itCity spelling doesn't match any contractor's service area. Use the canonical city name (e.g. "Oklahoma City", not "OKC").

What Happens After a 201

1
Lead is stored in the contractor app database.
2
The photo is auto-downloaded to private storage so the link can't break.
3
Up to 3 Premium contractors in that city get a 60-minute early-access window.
4
SMS notifications fire to all qualifying contractors (staggered).
5
The lead is unlockable by up to 3 contractors total, then marked sold out.
