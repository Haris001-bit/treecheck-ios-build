n8n Setup: Personal Lead Webhook

Estimated build time: 30–45 minutes

This guide is for the n8n developer setting up the automation that pushes leads from Mark's personal website into the Stump Commander app. It is a separate pipeline from the existing TreeCheck.ai webhook — same payload contract, different endpoint, different secret.

Why a separate endpoint? Leads from Mark's personal site are tagged as source: "personal" and auto-assigned to Mark. They are hidden from all other contractors, bypass the city-matching service area logic, and skip the broadcast SMS + Premium rotation that fires for normal TreeCheck.ai leads.

1. Endpoint

MethodPOST
URLhttps://wsbtxxobbvcdxiovnssi.supabase.co/functions/v1/create-personal-lead

Auth headerx-webhook-secret: <PERSONAL_LEAD_WEBHOOK_SECRET>
Secret: Mark will provide PERSONAL_LEAD_WEBHOOK_SECRET separately (do not commit it to n8n exports). Store it as an n8n credential or environment variable, not in plain workflow JSON. This is a different secret from LEAD_WEBHOOK_SECRET used by TreeCheck.ai — do not reuse.

2. Request payload

Identical to the existing TreeCheck.ai contract. All fields except urgency are required.

{
  "photo_url": "https://markswebsite.com/uploads/tree-photo.jpg",
  "city": "Edmond",
  "customer_name": "Jane Homeowner",
  "customer_email": "jane@example.com",
  "customer_phone": "+14055551234",
  "customer_address": "123 Main St, Edmond, OK 73034",
  "estimated_cost_min": 850,
  "estimated_cost_max": 1400,
  "job_type": "Tree Removal",
  "urgency": "As soon as possible"
}

Field rules

FieldTypeNotes
photo_urlstring (URL, max 2048)Must be publicly fetchable HTTP/HTTPS. Server downloads + archives to private storage automatically.
citystring (max 200)Free text. Service area matching is bypassed for personal leads.
customer_namestring (max 200)Required.
customer_emailstring (max 320)Must pass standard email regex.
customer_phonestring (max 50)E.164 (+14055551234) or US format ((405) 555-1234).
customer_addressstring (max 500)Full street address. Used for Google Maps deep link in the app.
estimated_cost_minnumber≥ 0.
estimated_cost_maxnumber≥ min, ≤ 1,000,000.
job_typestringMust normalize to one of: Tree Removal, Stump Grinding, Pruning/Trimming. Common aliases (e.g. "trimming" → Pruning) are accepted.
urgencystring (optional)One of: Emergency, As soon as possible (alias asap), Within a month, Flexible. Defaults to Flexible if omitted.

3. Responses

Success — 201 Created

{
  "success": true,
  "lead_id": "uuid-here",
  "source": "personal",
  "owner_contractor_id": "cf93d0f4-9365-4352-b0cb-10ce93646843",
  "job_type": "Tree Removal",
  "urgency": "As soon as possible",
  "message": "Personal lead created and auto-assigned to owner"
}

Error responses

StatusMeaningAction
400Validation failure (bad email, missing field, bad job_type, etc.)Check the error field in the JSON response. Do not retry — fix the payload.
401Missing or wrong x-webhook-secretVerify the credential. Do not retry blindly.
500Server error (DB insert failed, etc.)Safe to retry with exponential backoff (e.g. 3 attempts, 30s / 2m / 10m).

4. n8n workflow structure

  1. Trigger — whatever currently fires when Mark's website form is submitted (Webhook node, Form Trigger, or polling).
  2. Set / Function node — map your form field names into the exact JSON payload above. Coerce estimated_cost_min / estimated_cost_max to numbers (n8n form data is often strings).
  3. HTTP Request node:
    • Method: POST
    • URL: https://wsbtxxobbvcdxiovnssi.supabase.co/functions/v1/create-personal-lead
    • Headers:
      • Content-Type: application/json
      • x-webhook-secret: {{ $credentials.personalLeadSecret }}
    • Body: JSON, raw, paste payload referencing your mapped fields.
    • Response: parse JSON, capture lead_id.
  4. IF node — branch on success === true. On failure, send a Slack/email alert to Mark with the response body so bad payloads don't disappear silently.
  5. (Optional) Notify Mark — Email or SMS step on success. The app does not auto-send an SMS for personal leads (broadcast is intentionally skipped), so if Mark wants a phone alert, add it here.
Sanity test: Use "city": "Testville" with a fake customer record to verify the end-to-end flow. Mark can confirm it shows up in his Purchased Leads view with a green "From My Website" badge. Delete the test row from the DB after.
