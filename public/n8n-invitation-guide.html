Create Contractor Invitation — TreeCheck App

Overview

After your n8n workflow qualifies a contractor (insurance certificate approved via GPT), call the TreeCheck create-invitation endpoint to generate an invite link. Send this link to the contractor so they can set up their account and access the dashboard.

Endpoint

POST https://wsbtxxobbvcdxiovnssi.supabase.co/functions/v1/create-invitation

Headers

HeaderValue
Content-Typeapplication/json
x-webhook-secret5jhj47_C_P5_H5i
⚠️ Keep the webhook secret secure. Do not share it publicly or commit it to version control.

Request Body

{
  "email": "contractor@example.com",
  "application_id": null
}
FieldTypeRequiredDescription
emailstringYesContractor's email address
application_idstring / nullNoCan be null — only needed if tracking applications in the TreeCheck app

Successful Response 200

{
  "success": true,
  "invite_url": "https://app.treecheck.ai/accept-invite?token=abc123-...",
  "invite_token": "abc123-...",
  "expires_at": "2026-03-10T12:00:00Z"
}
FieldDescription
invite_urlThe full URL to send to the contractor. They click this to create their account.
invite_tokenThe raw token (if you need to construct the URL yourself).
expires_atInvitation expires in 7 days.

Error Responses

StatusMeaningAction
401Invalid or missing x-webhook-secretCheck the header value
400Missing emailEnsure email is in the request body
500Server errorRetry or contact the TreeCheck team

n8n Node Setup

1
Add an HTTP Request node after your GPT approval step
2
Method: POST
3
URL: https://wsbtxxobbvcdxiovnssi.supabase.co/functions/v1/create-invitation
4
Under Headers, add: x-webhook-secret = 5jhj47_C_P5_H5i
5
Body type: JSON — set email using the expression from your form data (e.g. {{ $json.email }})
6
Connect a Send Email or Send SMS node after, using {{ $json.invite_url }} from the HTTP response

Complete Flow

Website Form → GPT Insurance Check → ✅ Approved → HTTP Request (create-invitation) → Send invite_url to contractor

What Happens Next

When the contractor clicks the invite link:

1
They land on the TreeCheck account setup page
2
They create a password and fill in their company details
3
They choose Free or Premium tier
4
Their account is created and they can access the contractor dashboard
