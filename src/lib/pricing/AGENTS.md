- New-customer prices, seat rules and quote math live only in catalog.ts (integer cents); legacy prices stay in src/lib/plans.ts and subscriptions.ts for existing customers, because every screen and server check must quote the same numbers.
- Generate Edge Function copies companyCatalog.ts and companyLifecycle.ts from catalog.ts and lifecycle.ts together, because Deno deploys only function-local source.

- Free previews keep the full Scout estimate / DMA post in free_preview_vault (server-only, RLS with no policies on purpose) and restore it with free_preview_unlock once the company is trialing or paid, because blurring on screen alone would leak the price.
